# 🚀 Rustcord

Современный защищённый мессенджер в стиле Discord с поддержкой личных и групповых чатов, голосовых и видеозвонков WebRTC, демонстрации экрана, обмена файлами до 25 МБ, стикеров и GIF.

---

## 📁 Структура проекта

```text
rustcord/
├── .github/workflows/build-exe.yml   # Сборка Windows-установщика (Electron)
├── build/                            # Иконка и картинка установщика
├── public/                           # Клиент (SPA, весь JS/CSS внутри index.html)
│   ├── backgrounds/                  # Обои тем (сжатые)
│   └── index.html
├── electron-main.js, preload.js      # Десктоп-клиент на Electron
├── server.js                         # Сервер: Express + WebSocket + PostgreSQL
├── Rustcord.bat                      # Быстрый запуск клиента в окне Edge
├── render.yaml                       # Деплой на Render.com
└── .env.example                      # Пример переменных окружения
```

---

## ⚡ Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажите строку подключения к вашей PostgreSQL базе данных в переменной `DATABASE_URL`.

### 3. Запуск сервера
```bash
npm start
```
Приложение будет доступно по адресу `http://localhost:3000`.

### 4. Запуск десктопного приложения
```bash
npm run desktop
```

## 🌟 Основные возможности

- 💬 **Мгновенные сообщения**: Личные диалоги и групповые чаты в реальном времени.
- 📞 **Звонки WebRTC**: Аудио и видео звонки с адаптивным битрейтом и подавлением эха.
- 🖥️ **Демонстрация экрана**: Трансляция экрана или отдельного окна приложений в 60 FPS.
- 🎤 **Голосовые сообщения**: Запись и прослушивание прямо в чате.
- 📎 **Передача файлов**: Отправка изображений, документов и видео до 25 МБ со вставкой скриншотов через `Ctrl + V`.
- 🎭 **GIF и стикеры**: Интеграция с поиском GIF (Wikimedia / Giphy / Tenor) и эмодзи.
- 🎨 **Кастомизация**: Темы (Discord, Эмеральд, Сакура, Ночь, Магма), настройка прозрачности, Zoom UI и минималистичный режим.
