# Auralis

Auralis — desktop-клиент Rustcord с интерфейсом Liquid Glass. Клиент сохраняет возможности Rustcord: аккаунты, авторизацию, друзей, личные и групповые чаты, звонки, вложения, темы и настройки профиля.

## Как работает объединённая версия

- **Auralis** отвечает за название, визуальный стиль и desktop-оболочку.
- **Rustcord** остаётся источником серверной логики, API, WebSocket и PostgreSQL-базы. Существующие аккаунты и данные не переносятся и не дублируются.
- Локальный UI/API/WebSocket-прокси запускается автоматически вместе с Electron.
- Профильные стикеры 67, 777, 52 и 48 используют оригинальные SVG-стикеры в выборе, превью и публичном профиле.

## Запуск desktop-приложения

Требуется Node.js 18+.

```bash
npm install
npm run desktop
```

Отдельное окно Auralis автоматически поднимет локальный UI на `http://127.0.0.1:4173` и направит API и WebSocket на текущий backend `https://rustcord.hostless.app`. Поэтому для входа и обмена сообщениями нужен интернет.

## Запуск в браузере (необязательно)

Если нужен браузерный preview, запустите:

```bash
npm run preview
```

Затем откройте `http://127.0.0.1:4173`.

Если локальный preview уже запущен вручную, desktop-клиент использует его, а не пытается запустить второй сервер.

## Сборка Windows-установщика

```bash
npm run build:nsis
```

Установщик появится в папке `dist`. В сборку включены локальный preview-сервер и все файлы интерфейса.

## Backend

По умолчанию используется `https://rustcord.hostless.app`. Его можно переопределить:

```powershell
$env:AURALIS_BACKEND_URL = "https://your-backend.example"
npm run desktop
```

Ветка разработки: `rebrand/auralis-swiftcord-style`. Изменения этой ветки не публикуются на Hostless и не затрагивают `main`.
