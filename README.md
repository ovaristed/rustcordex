# Auralis

Auralis — отдельная локальная версия клиента с новым брендом и интерфейсом в духе Swiftcord: тёмный Liquid Glass, вертикальная панель разделов, полупрозрачные материалы, спокойные градиенты и более просторная область переписки.

Это отдельная ветка разработки. Изменения не попадают в `main` и не запускают Hostless deployment.

## Запуск локально

Требуется Node.js 18+.

1. Установите зависимости:

```bash
npm install
```

2. В первом окне терминала запустите локальный UI-прокси:

```bash
npm run preview
```

3. Откройте в браузере:

```
http://127.0.0.1:4173
```

Прокси отдаёт интерфейс из локальной папки `public/`, а запросы API и WebSocket пересылает на текущий backend `https://rustcord.hostless.app`. Поэтому локальная версия не требует локальной PostgreSQL, но для авторизации и обмена сообщениями нужно подключение к интернету и доступность backend.

### Открыть как desktop-приложение

Оставьте `npm run preview` запущенным. Во втором окне терминала выполните:

```bash
npm run desktop
```

Electron откроет локальный адрес `http://127.0.0.1:4173`. При необходимости адрес можно изменить через переменную `AURALIS_SERVER_URL`.

### Свой backend

```bash
# Windows PowerShell
$env:AURALIS_BACKEND_URL = "https://your-backend.example"
npm run preview
```

## Отдельная ветка

`rebrand/auralis-swiftcord-style`

Hostless workflow настроен только на `main`; эта ветка не разворачивается на хостинг.
