# Auralis

Auralis — desktop- и браузерный клиент Rustcord с интерфейсом Liquid Glass. Клиент сохраняет возможности Rustcord: аккаунты, авторизацию, друзей, личные и групповые чаты, звонки, вложения, темы и настройки профиля.

## Auralis 3.0\n\nВ версии 3.0 объединены предыдущие изменения интерфейса и серверной части:\n\n- Единая desktop-студия Liquid Glass: прозрачность 10–85%, размытие, цветовые настройки, эффекты и выбор обоев.\n- Пользовательские темы: собственный фон, сохранение и повторное применение пресетов.\n- Возвращена зелёная тема Emerald с оригинальными обоями.\n- Приватная desktop-админ-панель для владельца `ovarist`: список пользователей, блокировка с причиной и сроком, разблокировка, изменение ника и мыслей профиля. Админские действия проверяются на сервере; аккаунт владельца нельзя заблокировать через эту панель.\n- Существующие аккаунты, чаты и данные PostgreSQL сохраняются; миграции выполняются сервером при запуске.\n\n## Как работает объединённая версия

- **Auralis** отвечает за название, визуальный стиль и desktop-оболочку.
- **Rustcord** остаётся источником серверной логики, API, WebSocket и PostgreSQL-базы. Существующие аккаунты и данные не переносятся и не дублируются.
- Публичный сайт размещается на существующем Hostless-приложении `rustcord`; GitHub Actions автоматически отправляет туда коммит из `main`.
- Локальный UI/API/WebSocket-прокси запускается автоматически вместе с Electron.
- Профильные стикеры 67, 777, 52 и 48 используют оригинальные SVG-стикеры в выборе, превью и публичном профиле.

## Запуск desktop-приложения

Требуется Node.js 18+.

```bash
npm install
npm run desktop
```

Отдельное окно Auralis автоматически поднимет локальный UI на `http://127.0.0.1:4173` и направит API и WebSocket на текущий backend `https://rustcord.hostless.app`. Поэтому для входа и обмена сообщениями нужен интернет.

## Запуск в браузере локально

Если нужен локальный браузерный preview, запустите:

```bash
npm run preview
```

Затем откройте `http://127.0.0.1:4173`.

Если локальный preview уже запущен вручную, desktop-клиент использует его, а не пытается запустить второй сервер.

## Сборка Windows-установщика

```bash
npm run build:nsis
```

Установщик появится в папке `dist`. В сборку включены локальный preview-сервер, файлы интерфейса и production-зависимости приложения.

GitHub Actions автоматически собирает Windows installer при изменениях в `main`. Готовый артефакт доступен в Actions workflow run.

## Backend

По умолчанию используется `https://rustcord.hostless.app`. Его можно переопределить:

```powershell
$env:AURALIS_BACKEND_URL = "https://your-backend.example"
npm run desktop
```

## Публикация

Push в `main` запускает workflow публикации на Hostless. В существующем Hostless-приложении сохраняется backend Rustcord и его база данных; этот релиз обновляет код приложения до объединённой версии Auralis.
